磁力链接

直接粘贴磁力链接即可，无需选择文件。体积在元数据到达后补计限额， 超出预算会自动暂停进入等待队列。

种子文件

同样受每日下载限额约束：预算装得下立即开始，装不下自动进入等待队列。

限额上限

0 = 不限。立即生效并回写 config.yaml；用量仪表盘见「主页」。

默认下载目录

目录不存在会自动创建；立即生效并回写 config.yaml，但只影响之后新增的任务。

全局限速

速率层（跑多快）与每日容量限额（主页，每天跑多少）相互独立；0 或留空 = 不限速。
